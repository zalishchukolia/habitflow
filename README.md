# HabitFlow — Трекер звичок v1.1

Веб-застосунок для відстеження щоденних звичок з візуалізацією прогресу та статистикою.

## Технологічний стек
- React 18
- Vite
- Lucide React

## Запуск проєкту

npm install
npm run dev

Застосунок буде доступний на http://localhost:5173

## Функціональність
- Додавання та редагування звичок
- Щоденне відмічання виконання
- Тижневий календар прогресу
- Статистика за місяць
